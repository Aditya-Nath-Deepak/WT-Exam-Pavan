5. MONGODB
────────────────────────────────────────────────────────────────────────────────

mongod                                 (start local MongoDB server)
                                       → Should show: Waiting for connections on port 27017

--- LOCAL URI ---
  mongodb://localhost:27017/<db-name>
  mongodb://127.0.0.1:27017/<db-name>

--- MONGODB ATLAS URI (Cloud - Free) ---
  mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/<db-name>?retryWrites=true&w=majority

  How to get Atlas URI:
    1. Go to https://cloud.mongodb.com/
    2. Create free cluster → Connect → Drivers
    3. Copy the connection string
    4. Replace <password> and <db-name>

  Use either local or Atlas URI in your .env:
    MONGODB_URI=mongodb://127.0.0.1:27017/mydb          (local)
    MONGODB_URI=mongodb+srv://user:pass@cluster...       (Atlas)

--- Spring Boot application.properties ---
  spring.data.mongodb.uri=mongodb://localhost:27017/productdb    (local)
  spring.data.mongodb.uri=mongodb+srv://user:pass@cluster...     (Atlas)
  server.port=8080
  spring.security.user.name=admin
  spring.security.user.password=admin123

7. XAMPP SETUP (PHP Projects)
────────────────────────────────────────────────────────────────────────────────

1. Open XAMPP Control Panel
2. Start Apache + MySQL (both should turn green)
   NOTE: If MySQL won't start → Start Menu → Services → find "mysql" → Stop → retry

3. Place project folder in:  C:\xampp\htdocs\<your_folder_name>\

4. Access in browser:
   http://localhost/<your_folder_name>/index.php

PHP Built-in Server (no XAMPP needed):
   cd path/to/project
   php -S localhost:8000
   → Open: http://localhost:8000

8. MYSQL / PHPMYADMIN DATABASE SETUP
────────────────────────────────────────────────────────────────────────────────

Open:  http://localhost/phpmyadmin

1. Click "New" → Enter database name → Create
2. To import schema: Select DB → Import tab → choose schema.sql → Go

PHP DB connection:
   $conn = new mysqli('localhost', 'root', '', 'db_name');
   // Default XAMPP root password is empty ""

config.php:
   $host = "localhost";
   $user = "root";
   $pass = "";
   $db   = "user_auth";

9. POSTMAN GUIDELINES
────────────────────────────────────────────────────────────────────────────────

Download: https://www.postman.com/downloads/

Authorization:
   Type: Basic Auth
   Username: admin
   Password: admin123

REST Endpoints (Product Inventory):
   POST    /products           Create product
   GET     /products           Get all products
   GET     /products/{id}      Get by ID
   PUT     /products/{id}      Update product
   DELETE  /products/{id}      Delete product

POST / PUT Body → raw → JSON:
   {
     "name": "Laptop",
     "description": "Gaming Laptop",
     "price": 80000,
     "quantity": 10
   }

Common Errors:
   415 Unsupported Media Type → Use raw JSON, not form-data
   401 Unauthorized           → Check username/password + Basic Auth is set
